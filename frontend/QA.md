# 前端验证记录

验证环境：Node.js 22、桌面 Chromium 1440 × 1080、手机视口 390 × 844。所有验证均使用本地演示数据，不运行实际实验。

## 已完成

- `npm run check`：应用、数据、图标、预览服务器和构建脚本语法检查通过。
- `npm run build`：成功生成单文件 HTML；浏览器确认脚本与样式均内嵌。
- 桌面浏览器：候选搜索、验证状态筛选、IC50 排序、候选详情到原始证据的追溯正常。
- 名单交互：选择可保存并在刷新后恢复；锁定后不可修改；重置可恢复初始状态。
- JSON 导出：实际下载的文件包含 12 个演示候选、证据引用、`isDemo` 和 8 个明确保留的空位。
- 实验草稿：拒绝名单大小超过候选池；合法草稿可保存并在刷新后恢复；其他 campaign 不复用当前证据。
- 证据与版本：执行失败可单独筛选；OOM 保持未知预测、待验证状态；H2 保持候选状态，固定 Gate 规则可查看。
- 键盘：勾选和筛选后保留焦点；跳转主内容不改变路由；手机关闭侧栏时不可聚焦隐藏项，打开时隔离背景，关闭后恢复菜单焦点。
- 响应式：桌面与手机布局已截图检查；手机页面无整体横向溢出，宽表格在自身容器内滚动。
- 构建产物：通过本地 HTTP 打开单文件 HTML，候选数据与搜索正常；最终浏览器控制台未报告错误或警告。

## 范围

未连接真实 Controller、预测工具、评估器或数据库，因此没有端到端实验、权限隔离或算力计费验证。本记录不是自动化回归测试套件；后续接入后端时需补充接口与权限测试。

构建产物通过本地 HTTP 做浏览器验证；本次浏览器工具不支持直接访问 `file:` URL。
